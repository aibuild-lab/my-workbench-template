# My workbench

This is your private workspace for useful work with an agent. Open this folder
in Claude or Codex, explain what you want to make, and use your own context and
approved sources. The workbench works before you add a course.

- context/: your purpose, permissions, decisions and next step.
- work/: your drafts and finished work.
- library/: references you approve for this repository.
- blueprints/: reusable instructions and resources you choose to add.
- .aibl/: supplied-file ownership and installed versions.
- .aibl-local/: local learning state, never included in a Git push.

Review and save named files. Commit and push preserve different things; verify
your private remote before pushing. Keep sensitive material outside tracked
paths. Make a separate private backup of local learning state before changing
machines. Never reset the whole repository to recover one file.

Three supplied skills support the workbench: aibl-personalize records your
confirmed context, aibl-checkpoint saves or recovers selected work, and
aibl-enroll shows available programs and prepares the one you choose. Ask your
agent to explain the installed files and versions when you need an inventory.

Essentials teaches you to use this workbench. Its YouTube transcript blueprint
arrives when you request the lesson 8 resource. Workforce can be added here
after access. Keep using this same folder, your personal context and earlier
work. The end-of-day habit skill is yours to author when you reach that exercise.
