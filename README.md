# My workbench

This is your private workspace for Agent Essentials. The shared AIBL installer
creates your independent repository and installs the separate Essentials package.
Open this folder in your chosen app, then use the installed aibl-setup method.

- context/: your purpose, permissions, decisions and next step.
- work/: your drafts and finished work.
- library/: references you approve for this repository.
- course/essentials/: separately installed lessons and reference.
- .aibl/: supplied-file ownership and installed versions.
- .aibl-local/: local learning state, never included in a Git push.

Review and save named files. Commit and push preserve different things; verify
your private remote before pushing. Keep sensitive material outside tracked
paths. Make a separate private backup of local learning state before changing
machines. Never reset the whole repository to recover one file.

Workforce can be added here later after access. It does not replace your personal
context or earlier work. Your end-of-day skill is an Essentials exercise you
write yourself. This template does not pre-complete it.
