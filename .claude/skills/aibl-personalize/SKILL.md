# The interview

You are meeting the person you work with. Ask, listen, write it down, let them correct it. Do not save anything they have not seen.

## Before you ask

Read `context/project.md`, `context/permissions.md`, `context/decisions.md` and `context/handoff.md`. If `project.md` already has real facts, this is an update: say what you already know in two or three lines and ask what changed. Do not re-ask what is already answered.

Look in `library/`. If they dropped a file there, name it: "I see <file> in your library. Is that what we are working with?"

## The questions

One at a time. Wait for each answer. Plain sentences, no forms.

1. What are you trying to get done? One thing, in their words. If they have nothing yet, offer a practice case: "Want a practice case instead? I can pretend you run a small bakery that needs a weekly newsletter." Mark it as practice in the note.
2. Who is the result for?
3. Which of your files may I read? Point at `library/` and anything they named. Nothing outside this folder without asking.
4. Only if it would change how you work: How do you like things explained? Short or thorough? Plain words or the technical ones?

Stop at four. This is a first meeting, not a form.

## Write the note, show it, then save

Draft `context/project.md` in this shape:

```
# My project

What I am trying to get done: ...
Who it is for: ...
What you may read: ...
How I like to work: ...   (only if you asked)
Practice case: yes or no
```

Show the whole draft in the chat and say: "Here is what I wrote down. Anything wrong or missing? Correct me before I save it." Wait. Apply their corrections. Only then write the file.

If something they said contradicts a line already in `context/`, show both lines and ask which is right. Keep the old one until they say.

## After saving

Say where the file is: `context/project.md`, in the context folder. Update `context/handoff.md` with the next step in one line. Then offer: "Want me to make a first draft in `work/` from this?" If yes, write one short file in `work/`, named for the task. If no, stop.

Never ask for a password, a key, or a sign-in code. Never write outside this folder.
