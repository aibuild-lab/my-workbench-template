# Changelog

## 2026-11-01

- `aibl-update` in Codex: a new section, "In Codex: one permission for each protected write", lists every write the update makes to the workbench's history (`.git`), its `.agents` and `.codex` folders, anything outside the workbench, or the network: the `gh` checks, the `template` remote, the fetches and the update check (it fetches), the checkout of the chosen core paths, each commit, the `.codex/hooks.json` entry, a reconnected program remote, the merge, each clash's checkout and add, a cancel's `git merge --abort`, a revert, Start fresh's `answer`, both reapply commands, the recorder refresh, the home workbench record, and the checkpoint's save and push. Each runs as its own command, never joined with `&&`, `;` or `|`, with the app's permission asked together with it (never tried first), after one plain line that ends "Codex will ask you to allow it: choose Allow.". If it isn't allowed, or no permission can be asked, the update says that step's waiting line (what isn't in or saved, that nothing else changed or nothing is lost, and "try again") and does nothing else; it never hands the student a command. Every step that writes says so. Found in Wade's 11-01 hand checks: Codex refuses `.git` writes until the agent asks with the command, and an agent's own rules refuse a joined command. Claude Code is unchanged. New `tests/codex_permission.py`: every write the steps name is in the table and every unknown Git verb or script fails until classified; the student lines are plain; no joined commands; and, with Git's lock held the way Codex's refusal leaves it, a refused fetch, checkout, merge or abort changes nothing, and a refused commit after an allowed merge keeps the update's files unsaved until "try again" runs only the commit.

## 2026-10-30

- Camp detection in `--joining-from` now matches what the Agent Native OS workshop installer and Camp leave on a camper's computer. A verified sign is any one of: Camp's clone holding its descriptor; Camp's clone whose own `.git/config` names `aibuild-lab/agent-native-camp` or a private `agent-native-camp-private` mirror (a clone last updated before the descriptor reached Camp on 09-02 has only this); or `~/context-repo` holding Camp's `.camp-context-repo` marker. The clone is looked for at `~/GitHub` first, then at a few fixed places (`~`, Documents, Documents/GitHub, Desktop, and Windows' OneDrive Documents and Desktop). Reasons to ask: a Camp-named folder without either mark, `~/context-repo` without the marker, or `~/Documents/Agent-Native-Camp`. `~/.hermes` is no longer a sign: the Agent Native OS workshop teaches a local Hermes there too, so workshop alumni who never took Camp were asked. Still read only: fixed paths, three small files in Camp folders, no Git command in a Camp folder. `~/context-repo` opened by mistake stops like the Camp folder. The Camp question is now asked at most once, ever: the report gives `camp.next` (`say`, `ask` or `none`), and `--camp-record yes|no` writes `~/.aibl/camp.json` (schema `aibl.camp-answer/v1`, the same record the installer writes after its Camp line), after which neither surface asks or says it again. A strong sign never asks. Tests: old-installer layouts for Mac and Windows, and the once-only record, in `tests/joining_from.py`.
